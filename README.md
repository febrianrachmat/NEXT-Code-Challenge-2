# Q&A Forum API

RESTful API for a Simple Q&A Forum application, built with NestJS and PostgreSQL.

This project is the submission for **Code Challenge Milestone 2**.

## Status

Project scaffolding is in place. Feature work (auth, threads, docs) will follow in subsequent commits.

## Getting started

```bash
npm install
npm run start:dev
```

The API will be available at `http://localhost:3000`.
